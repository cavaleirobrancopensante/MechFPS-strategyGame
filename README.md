# MechFPS-strategyGame — Hive Breakers (working title)

A cockpit-view mech shooter with a hangar-management layer, made in
**Godot 4.7** (GL Compatibility renderer, works on Android).

The 3D view is faked with Wolfenstein-style raycasting over a 2D grid
map, so it runs light on phones and the whole game is plain GDScript:
no models, images or audio files.

- Open the folder in Godot 4.7 and press Play. It starts in the hangar.
- See [DESIGN.md](DESIGN.md) for the game design, controls and roadmap.

Version: **1.0a**
